# 🖤 Brown Note

A modern fragrance store built with HTML, CSS, and JavaScript.

## ✨ Features
- Browse and view perfumes
- Add to cart
- Checkout via WhatsApp
- Hidden admin panel for managing products

## 🔐 Admin Access
- Visit: `index.html#admin`
- Password protected
- Only admin can edit products and upload images

## 🛒 Checkout
- Products added to cart
- Orders sent via WhatsApp with full details

## 🚀 Run Locally
Open `index.html` in your browser
